# Example content (not published)

Nothing in this folder appears on the website. The site only reads the `content` folder.

These files show the shape of an episode, a guest profile, a topic and a clip so the team can see how
entries are structured. To preview the episode template locally, copy the files into the matching
folders under `content`, run `npm run dev`, and delete the copies afterwards.

Every name, title and detail here is an obvious placeholder. Do not publish them.
